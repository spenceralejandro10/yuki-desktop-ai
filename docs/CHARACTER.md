# Yuki — Character Bible

## Identidad
- Nombre: Yuki
- Tipo: mascota virtual de escritorio
- Estilo: personaje femenino japonés/asiático, visual moderno y amable.
- Uso: asistente animada de escritorio.

## Regla de consistencia visual
Todos los sprites deben mantener el mismo rostro, peinado, proporciones, paleta de color y vestuario aprobados en la referencia maestra.

## Diseño base aprobado
- Cabello oscuro, largo, recogido en cola alta.
- Atuendo casual/deportivo blanco con acentos rosados.
- Apariencia limpia, contemporánea y apta para animación.
- Fondo transparente en los assets finales.

## Entregables visuales
- Vista frontal.
- Vista 3/4.
- Vista lateral.
- Expresiones principales.
- Sprites de animación.
