# Yuki Desktop AI

Yuki es una mascota virtual de escritorio con animaciones por sprites, personalidad propia y futura integración con IA y voz.

## Estado
Proyecto inicializado.

## Flujo de trabajo
1. Diseño maestro del personaje.
2. Generación y validación de sprites.
3. Integración del motor de animaciones.
4. Ventana transparente de escritorio.
5. Estados interactivos.
6. Integración de IA, voz y memoria.
7. Pruebas y empaquetado.

## Estructura principal
- `docs/`: documentación funcional, visual y técnica.
- `assets/yuki/reference/`: referencias maestras del personaje.
- `assets/yuki/sprites/`: frames finales de animación.
- `config/`: configuración del personaje y animaciones.
- `src/`: código de la aplicación.
- `tests/`: pruebas.
